# Laboratory 04 - Cloud-Native Engineer

## Mission Overview

This laboratory focuses on cloud-native technologies, particularly Docker containers. The activity compares traditional Virtual Machines with containers and demonstrates how to deploy and manage a containerized Nginx web server.

## Objectives

- Differentiate Virtual Machines and Containers.
- Access a Docker-enabled cloud environment.
- Execute basic Docker commands.
- Deploy and manage an Nginx container.
- Document container operations using Markdown.
- Maintain an organized GitHub Cloud Computing Portfolio.
