# Cloud Provider Comparison

## Cloud Service Comparison

| Infrastructure Component                 | AWS        | Microsoft Azure                 | Google Cloud Platform |
| ---------------------------------------- | ---------- | ------------------------------- | --------------------- |
| **Compute**                              | Amazon EC2 | Azure Virtual Machines          | Compute Engine        |
| **Storage**                              | Amazon S3  | Azure Blob Storage              | Cloud Storage         |
| **Networking**                           | Amazon VPC | Azure Virtual Network           | Google Cloud VPC      |
| **Identity and Access Management (IAM)** | AWS IAM    | Microsoft Entra ID / Azure RBAC | Cloud IAM             |

## Guide Questions

### 1. Which cloud provider offers the broadest range of services?

AWS is widely recognized for offering a very broad range of cloud services. AWS describes its platform as providing a broad and deep set of cloud capabilities across areas such as compute, storage, databases, networking, analytics, and AI.

### 2. Which cloud platform would you recommend for an organization that primarily uses Microsoft products? Why?

Microsoft Azure would be a suitable choice because it integrates closely with Microsoft's ecosystem and identity services. Azure RBAC also provides role-based access control for managing permissions to Azure resources.

### 3. Which platform is widely recognized for Artificial Intelligence (AI), Machine Learning (ML), and Kubernetes services?

Google Cloud is widely recognized for its AI and machine-learning capabilities and its Kubernetes services. Google Cloud provides AI/ML tools and supports AI/ML orchestration through Google Kubernetes Engine (GKE).

### 4. What similarities did you observe among the three cloud providers?

All three providers offer equivalent fundamental infrastructure services for computing, storage, networking, and access management. Although their service names and implementations differ, the underlying purpose is similar: providing scalable resources for running applications, storing data, connecting systems, and controlling access.
