# Laboratory Activity 5 — The Cloud Data Engineer

## Mission Overview

This laboratory activity focuses on cloud data engineering and object storage. The activity includes researching cloud storage types, deploying MinIO using Docker, creating an object storage bucket, and uploading test data.

## Objectives

- Understand the differences between block, file, and object storage.
- Deploy MinIO using Docker.
- Configure MinIO using environment variables.
- Access a web-based object storage console.
- Create a storage bucket and upload data.
- Document the deployment process using Markdown.

## Tools Used

- GitHub
- KillerCoda
- Ubuntu Linux
- Docker
- MinIO
- MinIO Object Browser

## Skills Learned

- Comparing cloud storage technologies.
- Using Docker to deploy a cloud storage service.
- Working with Docker volumes and environment variables.
- Using Linux command-line tools.
- Creating and managing object storage buckets.
- Documenting technical procedures using Markdown.
